# Outline — AI Skill

## Capability
Self-hosted knowledge base and wiki (Notion alternative). Manages an Outline Docker container for team documentation, knowledge management, and collaborative editing with Markdown support, real-time collaboration, and full-text search.

## Type
Docker-based service (`outlinewiki/outline:latest`). Container port: **3000**. Host port: dynamically assigned by docker-manager (range 9000–9999).

## Dependencies
Requires **PostgreSQL** and **Redis** to be installed and running before Outline can be installed.
- `"requires": ["postgres", "redis"]` in app.json
- Install checks verify both services via `GET /api/services`

## Auth
Cloud Computer JWT token required for Docker management APIs. Outline internal auth: first user to access becomes admin (no separate admin password during install).

## Service Lifecycle

### Install & Start
- **POST /api/services/install**
  - **Body**:
    ```json
    {
      "appId": "outline",
      "installConfig": {
        "SECRET_KEY": "<auto-generated 64-char hex>",
        "UTILS_SECRET": "<auto-generated 64-char hex>",
        "DATABASE_URL": "postgres://outline:<pg-password>@<pg-host>:5432/outline",
        "REDIS_URL": "redis://<redis-host>:6379",
        "PG_HOST": "<postgres-container-name>",
        "PG_DATABASE": "outline",
        "PG_USER": "outline"
      }
    }
    ```
  - Security keys (SECRET_KEY, UTILS_SECRET) are auto-generated as 64-char hex strings via `crypto.getRandomValues()`.
  - DATABASE_URL is built from PostgreSQL service's container name, port 5432, and password from postgres installConfig.
  - REDIS_URL is built from Redis service's container name, port 6379.
  - Docker image `outlinewiki/outline:latest` is pulled and container is started automatically.
  - Volume: `${APP_VOLUME}:/var/lib/outline/data` — persistent storage for uploaded files.
  - **Response**: `{ ok, app, port, containerId }`

### Stop
- **POST /api/docker/stop**
  - **Body**: `{ "appId": "outline" }`
  - Removes the container and releases the allocated port.
  - **Response**: `{ ok: true }`

### Restart (Client-Side)
The component.js handles restart by stopping → re-reading config → re-running the container with saved installConfig. Wait time: ~8 seconds for Outline to initialize.

## API Endpoints

### GET /api/services/outline
Returns service status and connection details.
- **Response**:
```json
{
  "id": "outline",
  "running": true,
  "port": 9012,
  "containerName": "cloudpc-outline",
  "internalUrl": "http://cloudpc-outline:3000",
  "installConfig": {
    "SECRET_KEY": "...",
    "UTILS_SECRET": "...",
    "DATABASE_URL": "postgres://outline:pass@cloudpc-postgres:5432/outline",
    "REDIS_URL": "redis://cloudpc-redis:6379",
    "PG_HOST": "cloudpc-postgres",
    "PG_DATABASE": "outline",
    "PG_USER": "outline"
  },
  "installedAt": "2026-05-09T..."
}
```

### GET /api/docker/status/outline
Low-level Docker container status.
- **Response**: `{ running, containerId, port }`

### POST /api/docker/run
Start Outline container with full config.
- **Body**:
```json
{
  "image": "outlinewiki/outline:latest",
  "appId": "outline",
  "containerPort": 3000,
  "volumes": ["${APP_VOLUME}:/var/lib/outline/data"],
  "env": [
    "SECRET_KEY=<value>",
    "UTILS_SECRET=<value>",
    "DATABASE_URL=postgres://outline:pass@host:5432/outline",
    "REDIS_URL=redis://host:6379",
    "URL=/proxy/outline",
    "PORT=3000",
    "FILE_STORAGE=local",
    "FILE_STORAGE_LOCAL_ROOT_DIR=/var/lib/outline/data",
    "FILE_STORAGE_UPLOAD_MAX_SIZE=26214400",
    "FORCE_HTTPS=false",
    "PGSSLMODE=disable",
    "NODE_ENV=production"
  ],
  "restart": "always"
}
```

## Proxy Access
- **URL**: `/proxy/outline/` (iframe-embedded)
- **Mode**: `pathprefix`
- Docker-manager auto-discovers running container and caches proxy target

## Storage
- **Data**: `${APP_VOLUME}:/var/lib/outline/data` — uploaded files, attachments, images
- **Database**: Stored in PostgreSQL (separate service) — documents, collections, users
- **Cache**: Redis (separate service) — sessions, real-time collaboration state

## Key Environment Variables
| Variable | Value | Description |
|---|---|---|
| SECRET_KEY | Auto-generated 64-char hex | Encryption key for data at rest |
| UTILS_SECRET | Auto-generated 64-char hex | Utility encryption key |
| DATABASE_URL | postgres://user:pass@host:5432/db | PostgreSQL connection string |
| REDIS_URL | redis://host:6379 | Redis connection string |
| URL | /proxy/outline | Base URL for reverse proxy |
| PORT | 3000 | Internal container port |
| FILE_STORAGE | local | File storage backend |
| FILE_STORAGE_LOCAL_ROOT_DIR | /var/lib/outline/data | Local file storage path |
| FILE_STORAGE_UPLOAD_MAX_SIZE | 26214400 | Max upload size (25 MB) |
| FORCE_HTTPS | false | HTTPS forced (handled by proxy) |
| PGSSLMODE | disable | PostgreSQL SSL mode |
| NODE_ENV | production | Node.js environment |

## Features
- Rich Markdown editor with slash commands and block types
- Real-time collaborative editing
- Collections and nested document hierarchy
- Full-text search across all documents
- Document templates and versioning
- File attachments and image uploads (up to 25 MB)
- API access for programmatic document management
- Dark mode support
- Multi-language interface
- Import/export (Markdown, HTML, JSON)
- Integrations via webhooks and API

## CSS Prefix
All CSS classes use the `otl-` prefix to avoid conflicts with other apps.

## Troubleshooting
- **Container won't start**: Verify PostgreSQL and Redis are running first (`GET /api/services`)
- **Database errors**: Check DATABASE_URL format — password must be URL-encoded
- **Blank page after start**: Outline needs ~8 seconds to initialize; wait and refresh
- **File uploads fail**: Check volume mount and FILE_STORAGE_UPLOAD_MAX_SIZE setting
